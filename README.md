# 서비스 기획 및 아키텍처 설계서 (초안)

> ※ 본 문서는 프로젝트 진행 중 작성된 초안이며, 일부 항목은 팀 내 확정 전 상태입니다.

---

## 1. 프로젝트 개요

### 1.1 배경 및 목적
- 기존 주제였던 "채용공고 트렌드 대시보드"에서 "금융 뉴스 요약 및 시황 AI 인사이트 대시보드"로 주제를 전환함
- 전환 사유: 상업 목적이 아니더라도 크롤링을 통해 수집한 데이터를 정제 후 활용하는 방식이 포트폴리오용 프로젝트로 적합하지 않다고 판단
- 서비스 목표: **주식 입문자**도 국내외 시황과 관련 뉴스를 한눈에 파악하고, AI가 종합한 인사이트를 통해 시장 흐름을 쉽게 이해할 수 있도록 지원

### 1.2 데이터 범위
- **주식**: 국내 주식으로 한정
- **지표(지수) 및 금융 뉴스**: 해외 포함

### 1.3 핵심 컨셉
- 주식 입문자를 위해 전문 용어나 이해하기 어려운 내용은 강조 표시 후, 호버(hover) 시 설명을 제공

## 2. 서비스 페이지 구성

### 2.1 공통 고정 레이아웃
- **좌측 사이드**: 로고, 메뉴, 페이지별 콘텐츠, tip

- ※ 미정 사항: 캘린더/히트맵 페이지에서 좌측 사이드바 "페이지별 콘텐츠"에 구체적으로 어떤 내용이 들어갈지는 아직 미확정

## 3. 시스템 아키텍처

### 3.1 전체 데이터 흐름
```
[외부 API/데이터 소스]
  ├─ 한국투자증권 API (국내 주식 시세)
  ├─ finlight (금융 뉴스)
  └─ 네이버 뉴스 Search API (종목/섹터 뉴스)
        │
        ▼
[데이터 수집·정제 계층]
        │
        ▼
[RDB 적재 (ORM 기반, Supabase 연동)]
        │
        ▼
[FastAPI 백엔드]
   ├─ 도메인별 API 라우터 (timeline, calendar 등)
   └─ LLM API 연동 → 인사이트 생성 로직
        │
        ▼
[대시보드 (프론트엔드)]
   메인 페이지 / 캘린더 페이지 / 히트맵 페이지
```

### 3.2 기술 스택

**백엔드**
- **프레임워크**: FastAPI (uv 패키지 매니저)
- **DB**: Supabase 연동 예정

**프런트엔드**
- **프레임워크**: Next.js (App Router)
- **스타일링**: Tailwind CSS + shadcn/ui, 아이콘은 lucide 사용

### 3.3 저장소 구조

**백엔드 (`src/backend`)**
```
backend/
├── core/            # config, database
└── domain/
    ├── timeline/
    │   ├── models/
    │   ├── routers/
    │   ├── schemas/
    │   └── services/
    └── calendar/
        ├── models/
        ├── routers/
        ├── schemas/
        └── services/
```

**프런트엔드**
```
app/          # layout, page
components/
└── ui/       # shadcn/ui 컴포넌트
```

- 원격 저장소: `https://github.com/Prism-Sprint1/Gaemigul-app.git`
- 브랜치 전략: `main` + `<back|front>/feat/도메인명` (예: `back/feat/timeline`)

### 3.4 API 명세

**구현 완료**

| Method | Endpoint | 설명 |
|---|---|---|
| GET | `/timeline/indicators` | 헤더 지표 바 데이터 조회 (KOSPI, KOSDAQ, NASDAQ, S&P500, USD/KRW, NIKKEI) |

**연동 예정**
- 뉴스 API: finlight, 네이버 뉴스 Search API 예정
- 증시 일정/발표 API: pred 예정

## 4. 필수 구현 내용

1. 분석 대상 도메인 정의 및 데이터 수집·정제
2. RDB 스키마 설계 및 ERD 작성
3. ORM을 활용한 데이터 적재 및 조회 구현
4. FastAPI 기반 백엔드 API 구성
5. 제공된 LLM API 연동 및 인사이트 생성 로직 구현
6. 생성된 인사이트를 확인할 수 있는 대시보드(웹 화면) 구현
7. 데이터 수집부터 인사이트 생성까지의 처리 흐름(파이프라인) 구성
8. 예외 처리 및 오류 로깅
9. 구현 과정과 실행 방법 문서화
