## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트 주제 | 금융 뉴스 요약 및 시황 AI 인사이트 대시보드 (개미굴 / Gaemigul) |
| 해결하려는 문제 | 개인 투자자가 시세·뉴스·일정을 각각 다른 곳에서 확인하며 스스로 맥락을 재구성해야 하는 정보 파편화 문제 |
| 대상 도메인 및 데이터 | 국내 상장 주식(한정) + 해외 주요 지수·환율·금융 뉴스 |
| 사용 LLM API 또는 모델 | 미정 — 팀이 API를 지급받는 대로 연동 예정. 현재는 규칙 기반(통계 이상치 탐지 + 감성 키워드 사전) 로직으로 인사이트를 생성 중이며, LLM 연동 시 문장 생성부만 교체 가능하도록 설계 (3.7절 참고) |
| 주요 사용자·시나리오 | 주식을 시작한 지 얼마 안 된 투자자가 하루 중 정해진 시간대에 대시보드를 확인해 시황·뉴스·일정을 한 화면에서 파악 |

### 1.1 배경 및 목적

- 기존 주제였던 "채용공고 트렌드 대시보드"에서 "금융 뉴스 요약 및 시황 AI 인사이트 대시보드"로 주제를 전환함
- 전환 사유: 상업 목적이 아니더라도 크롤링을 통해 수집한 데이터를 정제 후 활용하는 방식이 포트폴리오용 프로젝트로 적합하지 않다고 판단
- 서비스 목표: **주식 입문자**도 국내외 시황과 관련 뉴스를 한눈에 파악하고, AI가 종합한 인사이트를 통해 시장 흐름을 쉽게 이해할 수 있도록 지원

### 1.2 데이터 범위

- **주식**: 국내 주식으로 한정
- **지표(지수) 및 금융 뉴스**: 해외 포함

### 1.3 핵심 컨셉

- 주식 입문자를 위해 전문 용어나 이해하기 어려운 내용은 강조 표시 후, 호버(hover) 시 설명을 제공

**[구현 현황]** `components/term.tsx` + `lib/glossary.ts`로 구현 완료
